# BSLMyVotes

Офлайн-фильтры личных голосов BeatSaverVoting для BetterSongList и Beat Saber PCVR 1.40.8.

## Установка

1. Закройте игру. Установите BSIPA, BetterSongList 0.4.2 и его зависимости: SongCore и BeatSaberMarkupLanguage. Совместимые версии берите для своей версии игры.
2. Скопируйте `BSLMyVotes.dll` из архива выпуска в каталог `Plugins` игры.
3. Запустите игру. В штатном списке фильтров BetterSongList появятся `My Likes`, `My Dislikes`, `My Voted`, `My Not Voted` (BetterSongList добавляет значок штекера).
4. Для отключения фильтра выберите `All`. Сортировка BetterSongList применяется к результатам как обычно.

Если фильтры скрыты, включите `AllowPluginSortsAndFilters` в конфигурации BetterSongList и перезапустите игру. При отсутствии обязательной зависимости BSIPA сообщает о ней и не загружает расширение.

BeatSaverVoting нужен для постановки голосов, но не для чтения уже сохранённой истории. Плагин читает только `UserData/votedSongs.json`, не изменяет его, не обращается к интернету и не использует публичный рейтинг.

## Обновление и ошибки

История читается в фоновом потоке при запуске и раз в секунду. Парсинг выполняется только при изменении содержимого. Перевыберите фильтр (при необходимости через `All`) спустя секунду после голосования, чтобы обновить отображаемый список. Уже открытая таблица автоматически не перерисовывается.

При отсутствии, повреждении или недоступности файла все четыре фильтра возвращают пустой результат. Старые голоса при ошибке сбрасываются; Not voted не выдаёт все карты за неоценённые. После восстановления файла данные подхватываются автоматически. Предупреждения пишутся при смене состояния ошибки, без сообщения для каждой карты.

Поддерживается фактический формат установленного BeatSaverVoting: JSON-объект, ключ — SHA-1 из 40 шестнадцатеричных символов, значение — `{ "hash": "тот же hash", "voteType": "Upvote" }` или `Downvote`. Регистр hash не важен. Повторяющиеся ключи, несовпадающие hash и неизвестные значения приводят к отклонению всей истории. Отсутствие записи в корректной истории означает Unknown. BeatSaver key не поддерживается и не подменяется hash.

Фильтр проверяет только уровни из переданного BetterSongList списка. OST исключаются, разные hash одной карты различаются. Поддерживается стандартный `custom_level_<hash>` и суффикс после пробела, используемый для дубликатов/WIP.

## Сборка

Нужны .NET SDK и reference assemblies .NET Framework 4.8 (Developer Pack). Локальные пути в исходниках не задаются: путь к игре передаётся MSBuild свойством.

```powershell
dotnet build BSLMyVotes.csproj -c Release "-p:GamePath=$env:BEAT_SABER_PATH"
dotnet run --project tests/BSLMyVotes.Tests.csproj -c Release "-p:GamePath=$env:BEAT_SABER_PATH"
```

`BEAT_SABER_PATH` задайте в своём окружении. Сборка использует установленные DLL и не копирует их в выпуск. Результат: `bin/Release/net48/BSLMyVotes.dll`. Исходники не требуют BeatSaverVoting.dll. Тестовый executable использует .NET 10 и минимальные типы хоста; успешная сборка самого плагина отдельно проверяет совместимость с реальными интерфейсами игры.

## Проверено

- Сборка Release против установленных BetterSongList 0.4.2 и DLL игры 1.40.8: 0 ошибок, 0 предупреждений.
- 36 автоматических проверок: Likes/Dislikes/Voted/Not voted, изменения голоса, неизвестные и разные hash, OST, повреждение JSON, отсутствие/удаление истории, восстановление, фоновое обновление, подавление повторяющихся предупреждений.
- Тест 5 000 карт и 10 000 голосов: 1,806 мс, Windows x64, .NET 10.0.3, прогретый predicate, без UI и загрузки JSON. Это измерение тестового хоста, не Unity/Mono.
- Локальная история проверена только чтением: 1 094 записи, все ключи имеют формат SHA-1; 327 Upvote, 767 Downvote. Личные данные не включены в исходники или выпуск.

**Проверка внутри VR-игры не выполнена.** Для приёмки остаются: загрузка BSIPA, наличие четырёх пунктов UI, сортировки, возврат полного списка через All, изменение голоса и повторный выбор фильтра, повторный запуск игры. Совместимость с реально запущенной игрой не объявляется подтверждённой до этой проверки. Установленный BetterSongList имеет gameVersion 1.37.4 в своём манифесте; расширение собрано против именно этой установленной версии, но это не заменяет игровой тест на 1.40.8.

## Исследование API

Исходные проекты: [BetterSongList](https://github.com/kinsi55/BeatSaber_BetterSongList), [BeatSaverVoting](https://github.com/Kylemc1413/BeatSaverVoting), [ExtraBSLSorters](https://github.com/thesupersonic16/ExtraBSLSorters).

Для точности установленной версии проверены метаданные и IL локальных DLL: BetterSongList 0.4.2 предоставляет `FilterMethods.Register<T>`, `IFilter` и `ITransformerPlugin`. Регистрация выполняется в OnStart до создания UI. BetterSongList применяет predicate к текущей коллекции, затем штатную сортировку. BeatSaverVoting предоставляет `CurrentVoteStatus`, но прямой зависимости ради него не требуется: `WriteVotes` сериализует весь словарь в локальный файл, путь которого строится относительно текущего каталога игры. Публичная подписка на изменения голосов в проверенном API не найдена. Поэтому используется независимое фоновое чтение файла. Исходники репозиториев через git в этой среде получить не удалось; выводы о целевой установленной версии сделаны по её DLL, а не по непроверенной ветке GitHub.
